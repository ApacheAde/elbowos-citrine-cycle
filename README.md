# Citrine Cycle

Full-colour Python 3 neon light-cycle arcade for ElbowOS.

Steer a glowing citrine bike that leaves a solid neon trail. Avoid walls and your own trail. Collect magenta energy orbs to score and gain speed.

Left / Right (or A / D) turn. Space resets.

## Play

```bash
pip install -r requirements.txt
python3 citrine_cycle.py --play
```

## Record a 9:16 reel

```bash
python3 citrine_cycle.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
